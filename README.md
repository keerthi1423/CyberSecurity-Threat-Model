# Cybersecurity Threat Modeling and Secure Configuration

## Project Overview

A beginner-friendly defensive cybersecurity project focused on identifying and prioritizing security risks in a fictional Student Portal Web Application.

## Objectives

- Identify application assets and trust boundaries.
- Analyze threats using the STRIDE framework.
- Evaluate risks based on likelihood and impact.
- Recommend prioritized security improvements.

## Application Scenario

The fictional Student Portal allows students to log in, view profiles, access course materials, and submit assignments.

## Project Deliverables

| File | Description |
|---|---|
| 01-Threat-Model.md | Threat modeling report and STRIDE analysis |
| Student-Portal-Threat-Model.drawio | Editable architecture diagram |
| threat-model-diagram.png | Exported threat model diagram |
| risk-register.md | Risk assessment and prioritization |
| hardening-checklist.md | Recommended defensive security controls |

## Methodology

The STRIDE framework was used to classify potential threats into Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege.

## Scope

This is a theoretical assessment of a fictional application. No external systems were tested and no real user information was used.

## Conclusion

This project demonstrates foundational cybersecurity concepts, threat identification, risk prioritization, and secure configuration recommendations.
